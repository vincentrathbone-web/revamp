# RevAmp keyboard shortcuts

The classic player's keys. Keys follow the physical key position, so they work on any keyboard layout;
`Num` means the number pad. Some keys mean something else while the playlist, equalizer or video window has
focus. Esc leaves fullscreen.

_This file is made from `src/app/keys.ts` by `npm run docs:keys`._

## Everywhere

| Keys | Does |
| --- | --- |
| `Z`, `Num4` | Previous track |
| `Ctrl+Z` | First track in the list |
| `Shift+Z` | Back 5 seconds |
| `X`, `Num5` | Play / restart |
| `C` | Pause |
| `V` | Stop |
| `Shift+V` | Fade out and stop |
| `Ctrl+V` | Stop after this track |
| `B`, `Num6` | Next track |
| `Ctrl+B` | Last track in the list |
| `Shift+B` | Forward 5 seconds |
| `J`, `NumDecimal` | Jump to file |
| `Ctrl+J` | Jump to time |
| `Ctrl+O` | Open playlist |
| `Ctrl+S` | Save playlist |
| `Alt+W` | Main window |
| `Alt+G` | Equalizer |
| `Alt+E` | Playlist editor |
| `Alt+V` | Video window |
| `Ctrl+Shift+K` | Visualization window |
| `Alt+K`, `Ctrl+K` | Visualization options |
| `Ctrl+W` | Window shade |
| `Ctrl+D` | Double size |
| `Ctrl+T` | Time elapsed / remaining |
| `Ctrl+P` | Preferences |
| `Ctrl+F1` | About |

| `F5` | Reload skin |
| `Alt+F` | Main menu |

| `Alt+F4` | Exit |
| `Ctrl+Tab` | Next window |
| `Alt+Enter`, `Ctrl+F` | Fullscreen |
